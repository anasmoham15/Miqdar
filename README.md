# Miqdar 🌙

A comprehensive Islamic companion app built for the Muslim community in the UK and beyond.

## Features
- 🕌 Prayer times based on your location
- 📖 Islamic stories sourced from verified books — categorised by topic and named figures
- 📅 Hijri calendar
- 🤲 Qibla direction

## Tech Stack
React · TypeScript · Tailwind CSS · Vite · Shadcn/ui

## Live Demo
[miqdar-gamma.vercel.app](https://miqdar-gamma.vercel.app)

## About
Miqdar was built to give Muslims a clean, reliable, all-in-one Islamic reference app. Unlike other apps, the stories section is sourced from real Islamic books — not AI-generated content — with named figures and verified details.

## Getting Started
git clone https://github.com/anasmoham15/Miqdar.git
cd Miqdar
npm install
npm run dev
